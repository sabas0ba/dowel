# ADR-0006: 名称は未確定。仮称 `dowel` を用いる

**状態**: Proposed

## 選定基準

- 4〜6文字
- CLI 名がそのまま動詞的に読める
- 既存 OSS・商標との衝突が少ない
- 日本語話者にも発音が一意

## 候補

| 候補 | 由来 | 所感 |
|---|---|---|
| `dowel` | ダボ（木材接合用の丸棒） | FFI = 接合を名称に主題化。衝突が少ない |
| `tenon` | ほぞ（継手の凸側） | 同上。tenon.io（別分野）が存在 |
| `kumiki` / `tsugite` | 組木・継手 | 一意性が最も高い。非日本語話者に発音の学習コスト |
| `lathe` | 旋盤 | 加工・生成の含意。英語圏で発音が割れやすい |
| `rebar` | 鉄筋 | 堅牢さの含意。PCIe Resizable BAR と表記衝突 |
| `splice` | 継ぎ合わせ | `splice(2)` と衝突 |

## 決定

`dowel` を採用する。ただし下記の調査結果を踏まえた確認が残る。

## 調査結果（2026-07 時点、一次調査は未了）

### 既存プロジェクト

| 対象 | 状況 |
|---|---|
| PyPI `dowel` | **使用中**。rlworkgroup/dowel（機械学習研究向けロガー、MIT）。更新は停滞している |
| npm `dowels`（複数形） | 使用中。jaredreich/dowels（クライアントサイドルーティングライブラリ） |
| crates.io `dowel` | 未確認 |
| GitHub org / ドメイン | 未確認 |

分野が異なるため混同の恐れは小さいが、**PyPI 名前空間は取得できない**。
本システムは Python 拡張の輸出を目標に含むため、
将来 PyPI へ何かを公開する場合は別名を要する。

### 商標

USPTO データベースの検索では、ソフトウェア分野（第9類・第42類）における
`DOWEL` の登録は確認されなかった。ただしこれは検索エンジン経由の間接的な確認であり、
TESS / TSDR による直接検索は未実施。

## 商標に関する認識の訂正

「一般名称は商標たり得ない」は、**その指定商品・役務に対して一般名称である場合**に限る。
`dowel` は木工用品に対しては記述的だが、ビルドシステムに対しては恣意的（arbitrary）であり、
この分類では強い識別力を持つ。

したがって次の2点が帰結する。

- 他者が第9類・第42類で `DOWEL` を登録する余地がある（現時点で未登録であっても）
- 逆に、こちらが登録を目指すことも可能である

## 未了事項

  実装着手前に必須

  これを先に固定しないと以後の用語が安定しない。候補: `peg`
